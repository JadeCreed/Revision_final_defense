SYSTEM LOGIC
The system has two seasons per year:
•	Wet Season
•	Dry Season
When the Admin creates a Seed Poll using the "Create New Poll" form, the poll is associated with a specific Season and Year.
Example:
Poll Title: Wet Season Seed Preference Poll
Season: Wet Season
Year: 2026
The poll choices must automatically come from the Seed Types and Seed Varieties master data.
After the poll is published, farmers can vote for their preferred seed varieties.
All submitted votes must be stored and displayed in the Seed Poll Results tab.
Once the poll is closed, the Admin can review the voting results and click "Finalize Seed Varieties".
Example Finalized Data:
Final Seed Varieties — Wet Season 2026
Hybrid:
•	Bigante Plus
•	Jackpot
Inbred:
•	RC-10
•	RC-18
After finalization, the system must create an Active Season Seed Profile.
IMPORTANT BUSINESS RULE
The finalized seed varieties become the official active seed varieties for the selected Season and Year.
These varieties must be used throughout the entire system and become the only valid seed choices for:
•	Beneficiaries Module
•	Seed Distribution Module
•	Reports Module
•	Harvest Module
•	Season Records Module
•	GIS Map Module
•	Crop Monitoring Module
•	Crop Utilization Module
•	Crop Phase Module
•	Production Module
Example:
Wet Season 2026 Active Seed Varieties:
Hybrid:
•	Bigante Plus
•	Jackpot
Inbred:
•	RC-10
•	RC-18
All records created under Wet Season 2026 must reference only these finalized seed varieties.
NOTIFICATION CREATION
After finalization, the system must automatically create a notification for Barangay President users.
Notification Example:
Title:
Confirmed Seed Varieties — Wet Season 2026
Message:
Wet Season 2026 seed varieties have been finalized and are now available for beneficiary processing.

ACTION BUTTON BEHAVIOR
When the Barangay President clicks:
[View Beneficiaries]
The system navigates to:
Beneficiaries Module
After clicking the action button, the notification status becomes:
Completed = True
When the user returns to the Home Page, the notification must no longer be displayed.
The notification should only appear again if a new Finalized Seed Variety set is created.
UNIFIED NOTIFICATION SYSTEM
Remove the separate "Pending Seed Pickups" section.
Pending Seed Pickups must become a notification and appear in the same notification area.
All actionable notifications must use the same design and flow.
Examples:
•	Confirmed Seed Varieties
•	Pending Seed Pickups
•	Distribution Schedule
•	Harvest Reminder
•	New Announcement
NOTIFICATION QUEUE
Only one active notification should be displayed at a time.
Example Queue:
1.	Confirmed Seed Varieties
2.	Pending Seed Pickups
3.	Distribution Schedule
4.	Harvest Reminder
When Notification #1 is completed, Notification #2 automatically appears.
When Notification #2 is completed, Notification #3 automatically appears.
No blank white space should remain after a notification is removed.
The remaining content must automatically move upward with a smooth animation.
REMOVE "YOUR TASKS"
Remove:
•	My Barangay Farmers
•	Announcements
•	Encode Harvest Data
•	Submit Report
Replace this section with 4 analytics tiles.

Below the analytics tiles, display:
Updates & Reminders
This section contains:
•	Announcements
•	Deadlines
•	Schedules
•	System Updates
BELL NOTIFICATION SYSTEM
The bell icon must no longer redirect to the News page.
When clicked, it must open a dropdown notification container with animation.
Format:

Unread notifications:
•	Light green background
•	Red indicator visible
Read notifications:
•	White background
•	Red indicator hidden
The bell icon must display the unread badge count.
Example:
🔔 5
When a notification is opened, the unread count decreases.
When the corresponding action is completed from the Home Page, the notification is marked completed and removed from the active notification queue.
